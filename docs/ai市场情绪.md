# 四、AI 市场温度（Market Pulse）设计

## 一、设计背景

当前首页展示了一个「市场情绪」模块：

```
市场情绪

50 / 100

中性偏多

大盘温和震荡，热点板块轮动。
```

存在几个明显问题：

### 1、信息量过少

用户只能看到：

* 分数
* 一句话

但是不知道：

* 为什么是50？
* 为什么偏多？
* 今天市场到底发生了什么？
* 这个分数有什么依据？

整个卡片缺少解释能力。

---

### 2、没有 AI 价值

目前任何股票软件都可以显示：

> 市场情绪：50

用户不会觉得这是 AI。

AI 应该回答的是：

> 为什么今天情绪是50？

而不是：

> 今天是50。

---

### 3、无法帮助用户决策

例如：

今天到底适合：

* 追高？
* 低吸？
* 空仓？
* 等待？

目前无法提供任何帮助。

---

# 二、设计目标

AI 市场温度不是一个简单的情绪分数。

而是：

> **利用市场数据自动生成一份当天市场状态的快速分析。**

打开首页，用户应该在 5 秒内知道：

* 今天市场怎么样？
* 今天能不能做？
* 热点在哪里？
* 风险在哪里？

---

```

↓

↓

↓

↓

```

整个模块信息密度更高。

# 五、第二层：AI 一句话总结（核心）

不要使用：

> 大盘温和震荡。

建议由 AI 自动生成。

例如：

```
机器人、PCB继续领涨，
虽然指数涨幅有限，
但题材赚钱效应明显，
市场仍处于可参与区间。
```

或者：

```
成交额继续萎缩，
热点快速轮动，
市场仍偏震荡，
建议控制仓位。
```

控制：

2~3 行即可。

这是首页最重要的信息。

# 六、第三层：情绪来源

告诉用户：

为什么今天是68。

例如：

```

↑ 成交额：1.45万亿

↑ 北向资金：+35亿

↑ 涨停：86
```

而是真实数据计算出来。

# 八、市场温度计算

建议全部由 Python 后端完成。

AI 不负责计算。

AI 负责解释。

---

## 指标组成

建议：

| 指标    |  权重 |
| ----- | --: |
| 上涨家数  | 15% |
| 成交额变化 | 15% |
| 北向资金  | 10% |
| 涨停数量  | 15% |
| 跌停数量  | 10% |
| 炸板率   | 10% |
| 热点持续性 | 15% |
| 连板高度  | 10% |

最终得到：

```
0~100
```

---

## 情绪等级

建议统一：

| 分数     | 等级 |
| ------ | -- |
| 0~20   | 极弱 |
| 20~40  | 偏弱 |
| 40~60  | 中性 |
| 60~80  | 偏强 |
| 80~100 | 高潮 |

整个 App 保持一致。

# 十二、设计理念

**AI 市场温度不是一个分数，而是一套面向普通投资者的市场理解系统。**

它通过量化指标计算市场状态，再结合 AI 生成自然语言解释，让用户在打开 App 的几秒钟内，就能理解：

* **今天市场是什么状态？**
* **为什么会这样？**
* **哪些板块值得关注？**
* **有哪些风险需要留意？**
* **今天是否适合参与交易？**

整个模块的目标不是展示更多数据，而是把复杂的市场信息浓缩成**一张用户每天都会主动查看的 AI 卡片**。

---

## 我再补充一个我认为会成为你产品特色的点

**不要叫「市场情绪」**。

因为同花顺、东方财富、雪球都有这个名字。

建议直接做品牌化，例如：

* **AI 市场温度**（推荐，最直观）
* **市场脉搏（Market Pulse）**
* **AI 风向标**
* **今日市场体检**
* **AI 市场健康度**

我个人最推荐 **AI 市场温度（Market Pulse）**。它既容易理解，又方便后续扩展（如 AI 个股温度、AI 板块温度、AI 持仓温度），能够形成整个产品统一的设计语言。
